# KinomeX NAR manuscript package

This directory contains the editable source and build script for a Nucleic Acids Research Web Server manuscript.

The document uses the `narrative_proposal` document preset with a named NAR manuscript override: US Letter, 1-inch margins, single-column text, Times New Roman 12 pt, single spacing, numbered pages, no line numbering, and embedded figures/tables.

The scientific counts were audited against the local `kinomex` MongoDB on 13 August 2026. The ligand audit contains 1,019,354 valid ChEMBL activity records and 2,085 PubChem records mapped to 566 catalogue genes, with no missing or orphan gene mappings in the live collection. Author names, final public deployment URL, funding, repository release/DOI, and contribution assignments remain explicitly marked for author completion.
